# Custom Binary File Archiver (RLE Algorithm)

Минималистичный бинарный архиватор на C++, реализующий последовательное сжатие файлов с использованием модифицированного алгоритма **Run-Length Encoding (RLE)**. Проект разработан как демонстрация навыков низкоуровневой работы с файловыми потоками, динамического манипулирования указателями записи/чтения (`seekp`/`tellp`) и проектирования кастомных форматов бинарных данных.

## ⚙️ Спецификация бинарного формата (.arh)

Архив представляет собой монолитный бинарный поток, состоящий из глобального заголовка и последовательности упакованных файлов.

### 1. Глобальный заголовок архива (Global Header)
| Смещение (байты) | Размер (байты) | Тип данных | Описание |
| :--- | :--- | :--- | :--- |
| 0 | 3 | `char[3]` | Магическое число / сигнатура формата (`"ARH"`) |
| 3 | 2 | `uint16_t` | Общее количество файлов в архиве |

### 2. Структура блока каждого файла (File Block Layout)
Сразу после глобального заголовка циклически идут блоки файлов. Каждый блок состоит из метаданных и бинарного тела.
